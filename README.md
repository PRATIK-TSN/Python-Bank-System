# Python Banking System

A simple Banking System built using Python that simulates real-world banking operations such as account creation, deposits, withdrawals, and authentication.

## Features

- Create new bank account
- Secure PIN authentication
- Deposit money (limit validation)
- Withdraw money (balance protection)
- Persistent data storage using JSON
- Input validation and error handling

## Technologies Used

- Python
- JSON file handling
- Object-Oriented Programming (OOP)

## How to Run

1. Clone the repository
2. Open the project folder
3. Run:

python main.py

4. Follow on-screen menu

## Project Purpose

This project was built to practice Python fundamentals, OOP design, and real-world logic implementation.
